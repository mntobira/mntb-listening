# 第2問 イラスト46枚 実測台帳

配布 PDF「第２問.pdf」に入っているイラスト **46 枚すべて**を1枚ずつ開き、
①〜④が実際に何を描いているかを目で確定させた記録。

## なぜこの台帳が必要か

第2問は「絵を選ぶ」大問なので、絵と選択肢が1つでもずれると
**答えが無い問題／答えが2つある問題**になり、誤答を覚えさせてしまう。

そして類題集 PDF は
- Part1（場面・対話・選択肢）
- Part3（画像生成プロンプト）

が一部ずれて綴じられている。配布された絵は Part3 のプロンプトどおりに
描かれているので、**絵は正しく、テキストの側の綴じ順がずれている**。

つまり「見出し S◯Q◯」を信用して絵を貼ると取り違える。
そこで見出しではなく**絵の中身**で対応を確定させ、その結果をここに残す。

## 表の読み方

- `見出し` … PDF 本文中の S◯Q◯（画像の直前に現れる見出し）
- `絵の中身` … 実際に描かれているもの
- `一致する問` … その絵の①〜④が4つとも噛み合うテキスト側の (セット, 問)
- `判定`
  - `OK` … 見出しどおりの問と4つとも一致 → そのまま使える
  - `ズレ` … 別の問の絵。対応表 `ILLUSTRATION_SOURCE_LABEL` で貼り替える
  - `要書き換え` … 絵自体は使えるが、テキストの選択肢が絵と噛み合わない
    → **絵は触らず、選択肢／対話／解説を絵に合わせて書き直す**

## ★実際に本番へ出ていた取り違え★

`public/listening_q2/el2_set14_q3.jpg` は
**「旅行の持ち物」の問なのに、家族写真の絵**が入っていた。

原因は、見出し S14Q3 の絵が家族写真（テキストでは第15セット問2 の題材）で、
旅行の持ち物のスーツケースは見出し S14Q2 の側に入っていたこと。
見出しをそのまま信じて貼っていたため、絵と問がまるごと入れ替わっていた。

同型の取り違えがもう1件あり、`el2_set4_q1.jpg`（公園）は
見出し S04Q1 と S03Q1 の両方が公園の絵で、中身が近いため
気付きにくいが、①〜④の対応は S04Q1 の側が正しい。

対応表 `ILLUSTRATION_SOURCE_LABEL` に登録して貼り替える。

## 「要書き換え」5問の扱い

ご指示は「絵を作り直すのではなくスクリプト側を直す」。
したがって**絵は1枚も作らず**、絵に描かれている内容に合わせて
選択肢・対話・設問・解説を書き直す。

| 問 | 絵の実態 | 書き換え方針 |
|---|---|---|
| 7-3 | ②③がどちらも真ん中の席。通路側が描かれていない | 「窓側／真ん中(隣に空き)／真ん中(詰まっている)／非常口横」ではなく、**脚の広さ**で区別できる選択肢に変え、正解を④非常口横（脚が伸ばせる席）にする |
| 8-3 | ①②が同内容。③④は服が2箱ぶん動く | 「どの荷物がどこへ行くか」ではなく、**服だけが複数の部屋に散る**という絵の特徴を使い、正解を①（3つが1対1に対応）にする |
| 11-1 | ③は6+7=13、④は12+12=24 | 選択肢の数字を絵の実数（13本・24本）に合わせて書き換える |
| 13-1 | ①〜④が地点、破線ルートは3本 | 「道順を選ぶ」問から**待ち合わせ地点を選ぶ**問へ書き換える |
| 16-2 | ③が C列3段目 | 選択肢③を「C列3段目」に、対話も C 列を指すよう書き換える |

## 最終結果（2026-08-30 反映後）

画像生成は **0枚**。すべて文章側の書き換えと張り替えで解決した。

### 1. 文章側を書き直した6問

`scripts/q2_figure_fixes.py` の `FIXES` に根拠つきで記録し、
`scripts/fix_q2_text_to_figures.py` が `q2_parsed.json` へ冪等に適用する。

| 問 | 新しい正解 | 書き換えた理由 |
|---|---|---|
| 6-3 | ② ダイニングテーブルのそば | 絵は単独の場所を指しており、組み合わせを選ぶ問になっていなかった |
| 7-3 | ④ 非常口の扉の隣 | ②③がどちらも真ん中の席。通路側の席が絵に無いので「足元の広さ」軸へ変更 |
| 8-3 | ① 1箱1部屋 | ①②が意味的に同一だったので「分けるか分けないか」軸へ変更 |
| 11-1 | ③ 6+7=13本 | 絵は 13本 と 24本 を描いており、12本／20本ではなかった |
| 13-1 | ③ 橋の先、キャンプ場に入る道 | ①〜④は道順ではなく地点。待ち合わせ地点を選ぶ問へ変更 |
| 16-2 | ③ C列 上から3段目 | 絵の③は C3 であり「B列3段目右側」ではなかった |

書き換え後は `fix_q2_text_to_figures.py --check` で
選択肢の重複・正解位置・「解説が正解の番号を明かしていないか」まで機械検査している。
