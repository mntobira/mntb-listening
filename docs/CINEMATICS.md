# とびら君の演出動画の台帳

`src/components/CinematicClip.tsx` の `CINEMATIC_CLIPS` が再生する動画。すべて `public/cinematics/` に置く（外部URL・有料APIを実行時に呼ばない）。
音声は入れない（`muted`）。効果音は対戦の効果音（`sfxSamples`）が担当する。

| ガチャ開封 | gacha.mp4 | 5.0秒 | 扉が開いて金色の光があふれる→光の粒→手を合わせて喜ぶ→元の立ち姿 | **2026-09-29 差し替え** Kling v3（Genspark）。最初と最後＝title.mp4 の1コマ目 |

- 参照画像：`public/mascots/cheering.webp`（勝利）・`basic.webp`（コンボの最初と最後）を正方形のクリーム背景に置いたもの。
- **透かし**：Genspark の表示用URLの動画には中央に「Genspark」の透かしが入る。生成元（fal）の原本には入っていないので、**原本から変換した**（720×720・24fps・H.264・音声なし・faststart）。
- 再生の上限：読み込み4秒・全体8秒で止まる（CinematicClip の安全装置）。動画はこれより短くする。
- 商用：Genspark の利用規約は生成物の商用利用を認め、第三者AI（Kling）の条件に従う責任を利用者に置く。生成に使ったのは運営者自身のキャラクター画像。
