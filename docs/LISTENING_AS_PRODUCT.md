# 英語リスニングを「売れる教材」として扱うための整理

ご要望「英語リスニングは普通に教材として売れそうだから、これはちょっとまた用途考えないといけない。
これのアドバイスもしてほしい」に対する回答。

**結論から言うと、私も売れると思う。ただし今の形のままでは売れない。**
理由と、何を変えるべきかを、実測値をもとに書く。

---

## 1. 今あるものの実測（推測ではない）

```
問題データ
  第1問A       5 問  (13.1 KB)
  第1問A追加  （EL1_A_EXTRA_PROBLEMS・別ファイル 110.7 KB）
  第1問B      75 問  (89.1 KB)
  第2問       54 問  (99.8 KB)
  第3問      105 問  (232.4 KB)
  ─────────────────────────
  データ合計 約 745 KB（解説込み）

音声
  public/listening_audio/   42 ファイル / 9.8 MB
  うち第2問 MP3   38問ぶん（16セット）/ 9.33 MB / 再生 10.2 分 / 平均 16.1 秒
  第1問          112 トラックがブラウザ読み上げで動作
```

対戦プールに出ているのは **146問（すべて4択）**。かな入力・2〜3択は0問。

### MP3 と ブラウザ読み上げの違い（`docs/LISTENING_AUDIO_VS_SPEECH.md` より）

| | MP3（第2問） | ブラウザ読み上げ |
|---|---|---|
| 設問文（"Question. Which…?"）を読む | **読む（38/38）** | **読まない（0/38）** |
| 声の種類 | **3種**（女 Adeline / 男 Mark / ナレーター Daniel） | 実質1〜2種 |
| 端末による差 | **無い**（全端末で同一） | **大きい**（iOS/Android/Windows で声も速度も違う） |
| 費用 | 生成に課金 | 無料 |
| オフライン | 不可（配信が要る） | 可 |

## 2. ★ここが商品価値の核心★

**「全端末で同じ音声が鳴る」ことが、この教材の一番の値打ちである。**

ブラウザ読み上げは無料だが、**端末によって声も速度も変わる**。
つまり **同じ条件で解けない**。これは学習教材として致命的である。

- 生徒A（iPhone）と生徒B（Android）が同じ問題を解いても、聞こえ方が違う
- 「聞き取れなかった」のが実力なのか端末のせいなのか **切り分けられない**
- 学校・塾が「うちの生徒全員に同じ演習をさせる」用途に使えない

MP3 はこれを解決している。しかも **声が3種類ある**。
共通テストのリスニングは「男女の対話」が中心なので、
声が1種類しかない読み上げでは **そもそも問題として成立しない**。

**つまり、MP3 化した38問は、無料のブラウザ読み上げでは代替できない。**
これが「売れる」理由である。無料版と有料版の差が、努力ではなく **物理的に埋まらない**。

## 3. 売り方の候補（3つ）

### 候補A — アプリ内の有料単元（一番おすすめ）

無料：第1問・第3問（ブラウザ読み上げ。実用上支障が小さいと確認済み）
有料：第2問（MP3・声3種・設問文も読み上げ）

**なぜこれが良いか**

- 無料部分だけで **すでに教材として成立している**（105問＋75問）
- だから「無料が使い物にならないから金を取る」形にならない
- 有料部分の価値が **聞けば1秒で分かる**（声が違う・設問文が読まれる）
- 追加開発が **課金の仕組みだけ** で済む

**懸念**：Firebase が Spark 無料枠なので、サーバー側の検証コードが書けない
（`docs/BATTLE.md` 参照）。課金判定をクライアントに置くと回避される。
→ 対策は §5 に書く。

### 候補B — 音声ファイル＋問題冊子のセット販売（アプリの外）

MP3 38問（9.33 MB）＋ PDF の問題冊子＋解答解説。
BOOTH / note / Gumroad などで単体販売する。

**なぜ良いか**

- **アプリの改修が1行も要らない**。今日から売れる
- 「教材を売る」ことと「アプリを育てる」ことを分離できる
- 学校・塾に **まとめ買い** してもらえる形にしやすい

**懸念**：MP3 はコピーできる。ただし教材はもともとそういうもので、
「コピーされるから売らない」は選択肢にならない。

### 候補C — 学校・塾への年間ライセンス

「全生徒が同じ音声で演習できる」を売り文句にする。
生徒ごとの正答率が見える管理画面をつける。

**なぜ良いか**

- **単価が一番高い**。個人向けの数十倍
- ★請求⑦-A の「裏側：生徒のつまずきを把握して学びを改善する仕組み」と
  そのまま重なる★ — 対戦アプリのために作る仕組みが、そのまま売り物になる

**懸念**：一番作るものが多い（管理画面・アカウント管理・請求）。
今すぐは無理。**最終的にここを狙う** という位置づけ。

## 4. 私の推奨する順番

```
第1段階（今すぐ・アプリ改修ゼロ）
  → 候補B。MP3 38問＋PDF を単体で売って、
    「そもそも買う人がいるか」を確かめる

第2段階（売れることが分かってから）
  → 候補A。アプリ内の有料単元にする

第3段階（学校から問い合わせが来てから）
  → 候補C。年間ライセンス
```

**理由：第1段階なら失敗しても失うものが無い。**
アプリを改修してから「誰も買わなかった」となるのが一番もったいない。

## 5. 今のうちに直しておくべきこと

### 5-1. ★MP3 を第2問以外にも広げるか、決める★

今 MP3 になっているのは第2問の38問だけ。
第1問・第3問は読み上げのままである。

**売るなら、どこまでを MP3 にするかを先に決めたほうがよい。**
あとから増やすと、買った人と買わなかった人で中身が変わる。

参考：第2問38問で 9.33 MB。第3問105問を同じ密度で作ると **約 26 MB**。
配信量としては問題ないが、生成の費用と時間はかかる。

### 5-2. 課金判定をクライアントに置かない設計にしておく

Firebase Spark 無料枠ではサーバー側のコードが書けない。
今の対戦は「正解がクライアントに露出することを認めたうえで、
不正しても割に合わない形にする」という設計にしてある（`docs/BATTLE.md`）。

だが **課金はそれでは済まない**。「音声ファイルの URL を知られたら終わり」になる。

対策の候補：

- **MP3 を署名付き URL で配る**（Cloudflare R2 / Firebase Storage の署名URL）
  → 有効期限つきの URL をログイン済みユーザーにだけ渡す
- **アプリ内課金を使う**（App Store / Google Play）
  → 判定をプラットフォームに任せられる。ただしアプリ化が要る
- **候補B（アプリ外で売る）なら、この問題自体が発生しない**

★これも「第1段階を候補Bにする」ことを推す理由である。★

### 5-3. 対戦プールの偏りを直す（これは教材としての価値に直結する）

```
english_listening   146問（4択 146 / 2〜3択 0 / かな入力 0）/ 未出題 98問
```

**すべて4択。かな入力も2〜3択も1問も無い。**
対戦としては単調だが、それ以上に **教材として弱い**。

リスニングで本当に力がつくのは「聞き取った語をそのまま書く」練習である。
かな入力（五十音パネル）は、まさにこれができる形式である。

→ 化学基礎と同じやり方（`docs/battle-authoring/`）で、
   **聞き取った語を答えさせる問題** を作れば、教材としての厚みが増す。

ただし ★英語リスニングは英単語なので、五十音パネルでは打てない★。
カタカナで答えられるもの（固有名詞・カタカナ語）に限るか、
**英字キーボードの入力形式を新設する** 必要がある。これは別途相談したい。

---

## 6. ★注意すべきこと（法務）★

**共通テストの過去問そのものを売ることはできない。**

今のデータが「共通テストの分析にもとづいて **独自に作った** 問題」なのか、
「過去問をそのまま収録したもの」なのかで、話がまったく変わる。

- 独自作成 → 売れる
- 過去問の複製 → **売れない**（著作権・大学入試センターの許諾が要る）

`src/data/englishListeningData.ts` の冒頭コメントには
「2025・2026年度 共通テスト本試験。河合塾／東進の分析より」とあり、
これは **大問構成の根拠** として分析を参照したという意味に読める。
問題本文そのものが独自作成なら問題ない。

★売り出す前に、ここだけは必ず確認してほしい。★
「形式を真似た独自問題」であることが説明できる状態にしておくこと。

## 7. まとめ

| 論点 | 私の意見 |
|---|---|
| 売れるか | **売れると思う** |
| なぜ | MP3 が全端末で同一・声3種・設問文も読む。**無料の読み上げでは物理的に代替できない** |
| どう売るか | まず **アプリの外で MP3＋PDF を単体販売**（改修ゼロ・失敗しても損が無い） |
| その次 | アプリ内の有料単元 → 学校・塾の年間ライセンス |
| 先に決めること | MP3 をどこまで広げるか / 課金判定の置き場所 |
| 先に確認すること | **問題が独自作成であること**（過去問の複製は売れない） |
| ついでに直すこと | 対戦プールが4択146問だけ。かな入力・2〜3択が0問 |
