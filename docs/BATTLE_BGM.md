# 対戦BGM（音源ファイル）の台帳

対戦のBGMは、`src/battle/audio/bgmFiles.ts` に登録した音源ファイルを鳴らす。
登録が無い（または読めない）ときは、従来どおり `battleAudio.ts` の合成音で鳴る。

## 曲の仕様（2026-09-29 利用者の指定）
| 曲 | 使う場面 | 作り方 |
|---|---|---|
| waiting（待合室） | 対戦メニュー・相手さがし・部屋で待つ・リスニング対戦のカウントダウン | ループ前提。はまる・うるさすぎない。**リスニング版にも同じ曲を入れる** |
| battle（対戦） | カウントダウン開始 → 対戦中（通常・残り3問・最終問題は同じ曲を流しっぱなし） | **曲頭から7秒は前奏（盛り上げ）、7秒ちょうどで本編（ドロップ）**。カウントダウン7・6…1の7秒後に START! が出るので、ここで曲が開く。感動系・続けたくなる・うるさすぎない（参考：Gravity 系の SNS アプリの BGM の雰囲気） |

- ループ：`loopStartSec`（本編の頭など）から曲末まで繰り返す。曲末と loopStartSec がつながるように作る。
- 音量：`gain` で合成音・効果音と揃える（目安 0.45〜0.6）。
- 途中から画面に入った（再接続など）場合も、残り時間から再生位置を計算して START! とドロップを揃える（`introOffsetSec`）。

## 商用の条件（必須）
- **無料枠・ベータ機能で作った曲は登録しない**（ElevenLabs Music は無料プランに商用権がない。有料契約中に生成したものは解約後も商用利用可、と公式の案内にある。2026-09-29 時点）。
- Genspark 経由で生成した場合も、Genspark の利用規約は第三者AI（ElevenLabs 等）の条件に従う責任を利用者に置いている。**生成元の有料契約の範囲で生成したこと**を記録する。
- 他社の曲（例：Gravity の BGM）をそのまま・似せて使わない。雰囲気の参考に留める。
