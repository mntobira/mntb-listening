# 問題の作り方（本番仕様と、整合性の守り方）

## 本番の第4問

| 設問 | 内容 |
|---|---|
| 問18〜21 | **完答で4点**（部分点なし）。イラスト並べ替え型は①〜⑤の5枚から4つを順に選ぶ（1枚はダミー）。グラフ完成型は**4つの系列名①〜④を各空欄に1つずつ割り当てる**（数値を選ぶ形式ではない） |
| 問22〜25 | **各1点×4**。**6つの共有選択肢①〜⑥**から各空欄に1つ選び、2つは使わない |

| 読み上げ | すべて**1回のみ**。約150〜165 wpm、CEFR A2〜B1相当 |

第4問の合計は **12点**です。

## 整合性をどう守っているか

データは `reference/sets/setNN.json` の1か所だけにあります。
PDF もアプリ用データも作業場サイトも、すべてこの JSON から作っています。
同じ内容を2か所に書くと、片方だけ直したときに必ず食い違うためです。

その上で、機械が次を全部チェックしています。1つでも引っかかると生成が止まります。

1. **並べ替え型**：正解4つ＋ダミー1つが①〜⑤をちょうど1回ずつ使っているか
2. **グラフ型**：正解が①〜④の並べ替えになっているか（同じ番号の重複がないか）
3. **問22〜25**：使わない選択肢2つが、正解4つから機械的に導けているか
4. **解説の根拠**：解説に挙げた英語表現が、スクリプトに**文字どおり存在するか**
5. **問26 の条件表**：全条件を満たす選択肢がちょうど1つで、正解と一致するか
6. **画像プロンプト**：日本語が1文字も混じっていないか
7. **語数**：問18〜21・問22〜25 は各78〜118語、問26 は1人33〜58語・合計150〜210語
8. **話者情報**：性別・年齢・アクセント・役柄・トーン・推奨Voice・4つの数値が全部あるか
9. **ダミーの根拠**：並べ替え型のダミーが、スクリプト中で明確に否定されているか
10. **全体の偏り**：型・難易度・性別・正解番号が偏りすぎていないか

とくに4番が重要です。解説の根拠がスクリプトに無ければ、
それは「もっともらしいが実際には音声で言っていない」解説であり、
学習者を誤らせます。これは機械で防ぐしかありません。
