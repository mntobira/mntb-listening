# 共通テスト英語リスニング 第4問 類題 15セット（マナトビ用）

## この ZIP は何か

共通テスト英語リスニング第4問（問18〜26）の類題 15 セット分のデータ一式です。
**音声 87 本と画像 45 枚が作成済みです。** 追加で作るのは音声 3 本だけです。
音声は ElevenLabs（Eleven v3）、画像は GPT Image 2 で作りました。

> **音声は容量の都合で 2 つの ZIP に分けています。**
> この ZIP に Set 1 〜 8 の 48 本、
> `共通テスト英語リスニング_第4問_音声その2_Set09-15.zip` に Set 9 〜 15 の 39 本。
> 両方をアプリの `audio/` にまとめて入れてください。

足りない 3 本は `足りない音声3本の作り方.md` を見てください。

## 組み込む順番

1. `既存ファイルの変更点.md` を読んで、既存ファイルを直す
2. `新規/data/` の2ファイルをアプリに置く
3. この ZIP の `新規/audio/`（48 本）と、音声その2 ZIP の `新規/audio/`（39 本）を
   まとめてアプリの `audio/` にコピーする（合計 87 本）
4. `新規/images/` の 45 枚を、アプリの `images/` にそのままコピーする
5. `足りない音声3本の作り方.md` を見て Set 15 の 3 本を作り、`audio/` に足す

手順 5 がまだでも、Set 1 〜 14 は完全に動きます。
Set 15 も 4A と 4B の 1 人目以外は音が出ます。
音声と画像は後から差し替えられるようにデータと分けてあります。
