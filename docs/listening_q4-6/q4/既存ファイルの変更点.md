# 既存ファイルの変更点（変更指示書）

新規ファイルは `新規/` にそのまま入っています。コピーするだけで済みます。
このファイルは**既存ファイルを直す作業**だけを書いています。
実際のファイル名はアプリ側の作りに合わせて読み替えてください。

---

## 1. 科目一覧に追加する

**対象**: 科目の一覧を持っているファイル（例 `src/data/subjects.ts`、
`src/constants/subjects.ts`、`public/data/index.json` など）

**やること**: 配列の末尾に1件足す。既存の項目は触らない。

```ts
{
  id: 'listening-q4',
  name: '共通テスト英語リスニング 第4問',
  category: '英語',
  kind: 'listening',
  sets: 15,          // セット数
  points: 12,         // 1セットの配点
  hasAudio: true,
  hasImage: true,
}
```

**確認**: 科目一覧の画面に「共通テスト英語リスニング 第4問」が出ること。
既存の科目の並びが変わっていないこと。

---

## 2. データの読み込みを1行足す

**対象**: 問題データを import しているファイル（例 `src/data/index.ts`）

**やること**: import を1行と、参照表への登録を1行足す。

```ts
import listeningQ4 from './listening-q4.json'   // ← 足す

export const POOLS = {
  // …既存はそのまま…
  'listening-q4': listeningQ4,                   // ← 足す
}
```

**注意**: `listening-q4.json` はセットの配列（`sets`）を持った1つの
オブジェクトです。他の科目が「問題の配列」を直接持っている作りなら、
`listeningQ4.sets` を渡すように書き換えてください。

---

## 3. 採点処理に「完答で4点」を足す

**対象**: 採点しているファイル（例 `src/lib/score.ts`）

**やること**: 問18〜21 は**4つ全部合っていて初めて4点**です。
1つでも違えば0点で、部分点はありません。
既存の「1問1点」の採点をそのまま使うと満点が変わってしまいます。

```ts
// 問18〜21（allOrNothing: true の設問）
const front = set.partA.front
const okFront = front.blanks.every((b, i) => answers[b.no] === b.answer)
score += okFront ? front.points : 0        // 4点 or 0点

// 問22〜25（各1点）
for (const b of set.partA.back.blanks) {
  score += answers[b.no] === b.answer ? set.partA.back.pointsEach : 0
}

// 問26（4点）
score += answers[26] === set.partB.answer ? set.partB.points : 0
```

**確認**: 1セット満点が **12点** になること
（4 ＋ 1×4 ＋ 4 = 12）。

## 4. 音声は「1回だけ再生」にする

**対象**: 音声プレイヤーの部品（例 `src/components/AudioPlayer.tsx`）

**やること**: `playOnce: true` のときは、再生し終わったあと
もう一度押せないようにする。本番が1回読みなので、
何度も聞けると練習にならないためです。

```tsx
const [played, setPlayed] = useState(false)
<audio onEnded={() => setPlayed(true)} … />
<button disabled={played}>再生</button>
```

復習モードでは制限を外してよいですが、本番モードでは必ず1回にしてください。

## 5. 画像の置き場所を通す

**対象**: 画像のパスを組み立てている場所

**やること**: データの中の `image` は
`images/set01_4A_front.png` のような**相対パス**です。
アプリの公開フォルダの位置に合わせて、頭に付けるパスだけ調整してください。

```ts
const src = `/assets/listening-q4/${item.image}`   // 例
```

音声の `audio` も同じ考え方です。

## 6. 問26 の条件は英語のまま出す

**対象**: 問26 の表示部分

**やること**: `conditionsEn` を問題として表示してください。
本番の問題冊子では条件は英語で印刷されます。
`conditionsJa` は日本語訳で、**解答解説のときだけ**出してください。
最初から日本語で出すと本番より易しくなってしまいます。

## 素材の置き方

`新規/audio/` と `新規/images/` の中身を、アプリの `audio/` と `images/` に
そのままコピーしてください。ファイル名はデータの `audioFile` / `imageFile` と
一致させてあるので、リネームは不要です。

Set 15 の `set15_4A_front.mp3` / `set15_4A_back.mp3` / `set15_4B_s1.mp3` の
3 本だけ未収録です。この 3 本は後から追加されます。
**音声ファイルが無いときにプレイヤーが落ちないようにしてください**
（読み込みエラーを拾って「音声準備中」と出すだけで十分です）。
