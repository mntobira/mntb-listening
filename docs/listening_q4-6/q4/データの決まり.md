# 第4問 類題データスキーマ（単一データソース）

`data/sets/set01.json` ～ `set15.json`。PDF・作業場サイト・ZIP はすべてこの JSON から生成する。
（＝スクリプト／正解／プロンプトの二重管理をやめ、整合性を機械的に保証する）

## 本番仕様の確定事項（2022〜2026 本試験・大学入試センター公式スクリプトに基づく）

| 項目 | 仕様 |
|---|---|
| 第4問A 問18〜21 | **完答で4点**（部分点なし）。イラスト並べ替え型は選択肢①〜⑤の5枚から4つを選ぶ（1枚はダミー）。グラフ完成型は**4本の系列名（カテゴリ）①〜④を各空欄に1つずつ割り当てる**（数値を選ばせるのではない） |
| 第4問A 問22〜25 | **各1点×4**。**6つの共有選択肢①〜⑥**から各空欄に1つ（2つは使わない） |
| 第4問B 問26 | **4点**。4人の説明を聞き、条件を満たすものを1つ選ぶ。選択肢は①〜④ |
| 読み上げ | すべて**1回のみ** |
| 語数目安 | 4A前半 約80〜100語 / 4A後半 約90〜110語 / 4B 各話者 約40〜50語（計約180語） |
| 速度 | 約150〜165 wpm |
| 4B の条件 | 問題冊子に**英語で**印刷される（A/B/C の3条件のメモ表）。※本試験では英語表記 |
| 4B の問い | `You are most likely to choose (26).` 等、英語1文 |

## 自動検証項目（scripts/validate.mjs）

1. `blanks[].answer` が選択肢の範囲内
2. 4A後半：4つの blank の answer が**互いに異なる**／`unused` が残り2つと一致
3. 4A前半 sequence：4つの answer ＋ dummy = {1,2,3,4,5} の完全被覆
4. 4A前半 graph：4つの answer が {1,2,3,4} の順列
5. **正解の根拠が script 内に実在するか**（keyPhrases の全要素が script に含まれる）
6. 4B：`matrix` の行が全 true な話者が**ちょうど1人**、それが `answer` と一致
7. 4B：各話者の script に3条件それぞれへの言及がある（keyPhrases で担保）
8. 語数が規定レンジ内（4A 80〜115語 / 4B 各話者 38〜55語）
9. 話者設定が15セットで偏っていない（性別・アクセントの分布チェック）
10. 表の blank 数＝4、blank 番号が 22〜25
