このファイルは**既存ファイルを直す作業**だけを書いています。

すでに第4問（`listening-q4`）や第5問（`listening-q5`）を組み込んである場合は、
**1・2・4・6 だけ**やれば済みます。3・5 は既存の仕組みに第6問ぶんを足すだけです。

## 3. 採点処理（第6問は完答なし・素直に足すだけ）

**対象**: 採点しているファイル（例 `src/lib/score.ts`）

第5問と違って**完答の単位はありません**。4問それぞれ独立で、
部分点もありません。合計 14 点です。

```ts
const s = set   // listening-q6.json の sets[i]

let score = 0
score += answers[34] === s.partA.q34.answer ? s.partA.q34.points : 0  // 3点
score += answers[35] === s.partA.q35.answer ? s.partA.q35.points : 0  // 3点
score += answers[36] === s.partB.q36.answer ? s.partB.q36.points : 0  // 4点
score += answers[37] === s.partB.q37.answer ? s.partB.q37.points : 0  // 4点
```

**確認**: 1セット満点が **14点** になること（3 ＋ 3 ＋ 4 ＋ 4 = 14）。

**問36 の選択肢は人数で、順番が直感と違います。**

```
① 1人   ② 2人   ③ 3人   ④ 0人
```

**④が「0人」**です。本番もこの並びなので、勝手に 0→1→2→3 の順に
並べ替えないでください。`q36.choicesJa` にこの4つが入っています。

## 4. 問37 は画像が選択肢（★第6問で最も大きな変更）

**対象**: 選択肢を描いている部品

問37 は「①〜④のグラフのうち、その発言の根拠はどれか」を選ぶ問題です。
**文字の選択肢はありません。4枚のグラフそのものが選択肢**です。

```tsx
// 4枚を 2×2 に並べ、タップで選ばせる
<div className="grid grid-cols-2 gap-3">
  {set.partB.q37.graphs.map((g) => (
    <button key={g.no} onClick={() => choose(37, g.no)}
            className={selected === g.no ? 'ring-2 ring-orange-500' : ''}>
      <span className="font-bold">{'①②③④'[g.no - 1]}</span>
      <img src={imgPath(g.image)} alt="" />
    </button>
  ))}
</div>
```

**縦1列に並べないでください。** 4枚のグラフは互いに見比べて
初めて違いが分かります（数字は同じで対象だけ違う、など）。
1枚ずつスクロールさせると比較できず、本番より難しくなります。

**画像がまだ無いときの代用**: `graphs[].series` に系列名と数値が
入っています。簡易的な棒グラフや表として描けます。

```tsx
{g.series.map((x) => (
  <div key={x.name}>
    <span>{x.name}</span>
    <div style={{ width: `${(x.value / max) * 100}%` }} className="h-3 bg-slate-600" />
    <span>{x.value}{g.kind === 'pie' ? '%' : ''}</span>
  </div>
))}
```

## 5. 音声は「1回だけ再生」・1セット2本

**対象**: 音声プレイヤーの部品（例 `src/components/AudioPlayer.tsx`）

第6問の音声は**A・B の2本だけ**です。どちらも文字列1つで、
配列ではありません（第5問の問32 のような複数ファイル再生は不要）。

```
partA.audio   … A の対話（問34・問35 用）。2人の掛け合いが1本に入っている
partB.audio   … B の会話（問36・問37 用）。3人の掛け合いが1本に入っている
```

`playOnce: true` なので、再生し終わったらもう一度押せないようにしてください。

**A と B は別々の問題として扱ってください。**
A を聞いて問34・35 に答え、そのあと B を聞いて問36・37 に答えます。
A と B に内容のつながりはありません（本番も別の話題です）。

## 7. 問36 の解説には「なぜ数えないか」を必ず出す

**対象**: 解答解説の表示部分

問36 は「以前よりも」がポイントで、**もともとその行動をしている人は
数えません**。ここを説明しないと、学習者は何度でも同じ間違いをします。

`q36.stances[]` に話者ごとの判定が入っています。

| キー | 意味 |
|---|---|
| `who` | 話者名 |
| `shifted` | **数えるかどうか**（true = 数える） |
| `alreadyDoing` | もともとそうしているか |
| `trap` | 引っかけの型（下の表） |
| `evidence` | 根拠となる発言（音声にそのまま出てくる） |
| `why` | なぜ数える／数えないかの日本語説明 |

| `trap` の値 | 意味 | 数える |
|---|---|---|
| `alreadyDoing` | もともとそうしている | × |
| `soundsLikeRefusal` | 渋る言い方だが結局動く | ○ |
| `agreesButNoAction` | 同意するが自分は動かない | × |
| `conditionUnmet` | 条件つきで、その条件が満たされない | × |

`q36.shiftedCount` に「数える人数」が入っていて、
これがそのまま答え（1人→① 2人→② 3人→③ 0人→④）になります。
解説画面ではこの表をそのまま出すのがおすすめです。

## 8. B は「状況」の下に話者名入りのメモ表を出す（★本番の冊子と同じ）

**対象**: B の問題画面（状況を出しているところ）

本番の第6問B では、問題冊子の状況文のすぐ下に
**話者名が入った3行の空欄表**が印刷されていて、
「後の表にメモを取ってもかまいません。」と書かれています。
受験者はここに聞き取った内容を書きながら問36 に答えます。
この表が無いと、3人の立場を整理する練習ができません。

データはこうなっています。

```json
"partB": {
  "situation": "三人の学生(Colin, Riko, Bianca)が，自転車通学のヘルメットについて話をしています。",
  "memoTable": {
    "lead": "後の表にメモを取ってもかまいません。",
    "rows": [
      { "who": "Colin",  "note": "" },
      { "who": "Riko",   "note": "" },
      { "who": "Bianca", "note": "" }
    ]
  },
  ...
}
```

| キー | 意味 |
|---|---|
| `lead` | 表の上に出す一文。そのまま表示してください |
| `rows[].who` | 話者名。**`partB.speakers[].name` と同じ順番**です |
| `rows[].note` | **必ず空文字**。受験者が書き込む欄なので、何も表示しません |

表示のしかた（第4問B の条件メモ表と同じ作りで構いません）。

```tsx
<p className="text-sm font-bold">{set.partB.memoTable.lead}</p>
<table className="w-full border border-slate-600 text-sm">
  <tbody>
    {set.partB.memoTable.rows.map((r) => (
      <tr key={r.who}>
        <th className="w-24 border border-slate-600 bg-slate-50 p-2 text-left">{r.who}</th>
        <td className="border border-slate-600 p-2">
          <input className="h-9 w-full" placeholder="" />
        </td>
      </tr>
    ))}
  </tbody>
</table>
```

- 紙で出すときは**高さ11mm 程度の空欄**にしてください（本番の冊子と同じ幅感）。
- アプリで出すときは入力欄にして構いませんが、**採点対象にはしないでください**。
  ここはあくまで下書きで、点数は問36・問37 だけで決まります。
- 行を増やしたり減らしたりしないでください。**必ず3行**です。

### あわせて：`situation` は「話者名入り・第三者視点」です

本番の状況文は「あなたは〜」ではなく、
**話者名を明記した第三者視点**で書かれています。

```
A: Owen と Nadia が，スペイン語の講座をどの形式で受けるかについて話をしています。
B: 三人の学生(Colin, Riko, Bianca)が，自転車通学のヘルメットについて話をしています。
```

`situation` の中に出てくる名前は `speakers[].name` と一致しています。
表示時に「あなたは…」へ書き換えないでください（本番と形式が変わってしまいます）。
