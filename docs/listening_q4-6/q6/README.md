# 共通テスト英語リスニング 第6問 類題 15セット（マナトビ用）

## この ZIP は何か

共通テスト英語リスニング第6問（問34〜37）の類題 15 セット分のデータ一式です。
音声 30 本は **`新規/audio/` に完成品が入っています**（作り直す必要はありません）。画像 60 枚は **`新規/images/` に完成品が入っています**（作り直す必要はありません）。

## 組み込む順番

1. `既存ファイルの変更点.md` を読んで、既存ファイルを直す
2. `新規/data/` の2ファイルをアプリに置く
3. `新規/audio/` の音声 30 本をそのまま置く（作業不要）
4. `新規/images/` の画像 60 枚をそのまま置く（作業不要）

音声と画像がまだ無い状態でも、問題文・選択肢・解答解説は表示できます。
問37 の図表は `graphs[].series` に数値が入っているので、
画像が無い間は表やその場描画のグラフで代用できます。

## 第4問・第5問との違い（先に読むと楽です）

| | 第4問 | 第5問 | 第6問 |
|---|---|---|---|
| 配点 | 12点 | 16点 | **14点** |
| 完答の単位 | 問18〜21 の4問 | 問28・29／問30・31 | **なし（1問ずつ独立）** |
| 音声の本数 | 6本／セット | 4本／セット | **2本／セット** |

**第6問でいちばん変わるのは画像の扱いです。**

4枚のグラフが**選択肢そのもの**です。文字の選択肢はありません。
アプリ側では4枚を2×2に並べ、タップで選ばせてください。
詳しくは `既存ファイルの変更点.md` の「4. 問37 は画像が選択肢」を見てください。
