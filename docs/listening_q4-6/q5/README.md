# 共通テスト英語リスニング 第5問 類題 15セット（マナトビ用）

## この ZIP は何か

共通テスト英語リスニング第5問（問27〜33）の類題 15 セット分のデータ一式です。
画像 30 枚は **`新規/images/` に完成品が入っています**（作り直す必要はありません）。
音声ファイルは入っていません。ElevenLabs で作ってから `audio/` に
同じ名前で入れてください（設定値は `音声の作り方.md`）。

## 中身

```
新規/
  data/listening-q5.json          アプリが読むデータ本体（15セット）
  data/listening-q5.ts            上と同じ内容の TypeScript 版（import 用）
  audio/                          ここに音声を入れる（今は README だけ）
  images/                         画像 30 枚（完成品・そのまま置ける）
既存ファイルの変更点.md            既存ファイルを直す手順（← 必ず読む）
音声の作り方.md                    ElevenLabs の手順と設定値
画像の作り方.md                    GPT Image 2 の手順と注意
作る音声の一覧.csv                  60 本ぶんの設定とスクリプト（会話は発話ごとに行を分けています）
作る画像の一覧.csv                  30 枚ぶんのプロンプト
問題の作り方.md                    本番仕様と、どうやって整合性を守っているか
reference/
  sets5/q5setNN.json              元データ（画像プロンプトも入った完全版）
  第5問_類題15セット.pdf            印刷用（問題・解答解説・スクリプト・プロンプト）
```

## 組み込む順番

1. `既存ファイルの変更点.md` を読んで、既存ファイルを直す
2. `新規/data/` の2ファイルをアプリに置く
3. `音声の作り方.md` を見て音声を作り、`audio/` に置く
4. `新規/images/` の画像 30 枚をそのまま置く（作業不要）

音声がまだ無い状態でも、問題文・選択肢・解答解説は表示できます。
音声と画像だけ後から差し替えられるようにデータを分けてあります。
