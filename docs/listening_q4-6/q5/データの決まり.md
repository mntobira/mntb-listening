# 第5問 類題データスキーマ（単一データソース）

`data/sets5/set01.json` ～ `set15.json`。PDF・作業場サイト・ZIP はすべてこの JSON から生成する。
（＝スクリプト／正解／プロンプトの二重管理をやめ、整合性を機械的に保証する）

## 本番仕様の確定事項

出典：大学入試センター公表の小問別配点・正答率データ（旺文社教育情報センター 2026-03-17 集計）、
全国英語教育研究団体連合会「令和8年度本試験 英語（リスニング）関係団体評価」、
東進／Z会 2024〜2026 設問別分析、2024〜2026 本試験スクリプト実測。

| 設問 | 形式 | 選択肢 | 配点 | 2026 正答率 |
|---|---|---|---|---|
| 問27 | ワークシート冒頭＝**講義の大意**を埋める | **4択（独立）** | **3点** | 59.3% |
| 問28・29 | ワークシート空所（前半ブロック＝従来／現状） | **6択共通（問28〜31 で共有）** | **完答2点** | **12.7%** |
| 問30・31 | ワークシート空所（後半ブロック＝利点／方策） | 同じ6択 | **完答2点** | 35.2% |
| 問32 | メンバー A・B の発言が講義と一致するか | ①Aのみ ②Bのみ ③両方 ④どちらも違う | **4点** | 18.7% |
| 問33 | 講義＋会話＋図表を統合して言えることを選ぶ | **4択** | **5点** | 43.7% |
| | | | **計16点** | |

### 読み上げと構成

- 音声は**すべて1回のみ**。速度 約150〜160 wpm。
- 問題冊子には「状況」（日本語）と「活動1／活動2／活動3」（日本語）が印刷される。
- 問32 は A・B 2人の発言をメモする欄が印刷される。
  問33 には「余白を使ってメモを取ってもかまいません」の指示がある。
- 音声は3本に分かれる：
  1. **講義**（問27〜31 用）… 実測 270〜280 語（2024:270 / 2025:278 / 2026:280）、約110秒
  2. **問32 の2発言**（メンバー A・B）… 各 **9〜13 語の1文**
  3. **問33 の会話**… 計 **60〜75 語 / 3〜4発話**
     本番は「Joe と May との三人で」＝**受験者を含めて三人**なので、
     実際に声が入るのは **2人**（Joe と May）。音声の話者は2人で作る。
- 講義の話者は1人（大学の講師）。問32・33 は別話者。

### 第5問の設計原理（最重要）

**問28〜31 は「聞こえた語がそのまま入ることはほぼ無い」。必ず言い換えを1段挟む。**
本番の実例：

| 年度 | 講義の音声 | ワークシートの正解 |
|---|---|---|
| 2026 問28 | `common` | **widespread** |
| 2026 問29 | `great financial rewards` | **profitable** |
| 2026 問30 | `get fewer deadly diseases` | **improved** |
| 2026 問31 | `instead of being wasted` | **reused** |
| 2024 問28 | `blow air into hot glass` | **Blown into** |
| 2025 問30 | `made the first group feel regifting was OK` | **acceptable** |

さらに **空所の直前後の語との文法的な繋がり**も制約になる（2026問29 は `highly ___` なので
`highly widespread` が不自然、という消去が必要）。これを本データでは
`collocationNote` に明記し、バリデータで「空所ラベルに前後の語が含まれること」を検査する。

### 選択肢6個の作り方（誤答の質を担保する）

本番の指示は **「同じ選択肢を2回以上使ってもかまいません。」**である。
したがって

- 4つの空所の正解が**重複してよい**（同じ番号を2回以上入れてよい）
- 結果的に使われない選択肢の**個数は固定されない**（2個とは限らず、0個にもなる）
- **「使わない2つ」を前提にした個数消去法は使えない**。教材の文言でも書かない。

`unused` は「6個から正解の集合を引いた残り」を機械的に入れるだけの派生値。
表示に使うときは「結果的に使わない選択肢」と書き、空のときは「（なし）」を出す。

結果的に使われない選択肢は次のいずれかであること：
- **講義に出た語の直訳**（例：2026 の `experimental` `researched` は講義の
  `are experimenting` `More research is needed` に引っ張られる）
- **正解と品詞・語形が同系**で、意味だけ合わない語

### 英文選択肢はアルファベット順（本番準拠）

本番の第5問の英文選択肢（問27・問28〜31 の6択・問33）は、**すべてアルファベット順**。
`①〜⑥` に意味的な順序は無い。

並べ替えのキー（`scripts/alphabetize.py` と `validate5.mjs` が同じ規則を使う）：

1. 前後の空白を落として小文字化
2. 先頭の冠詞 `the` / `a` / `an` を無視
3. 英数字と半角スペース以外の記号を無視

並べ替えるときは `answer` / `distractors[].no` / `blanks[].answer` / `unused` と、
`explain` 内の丸数字を必ず同時に付け替える。
**講義・問32・問33 の音声スクリプトは絶対に変更しない**
（すでに収録済みのため。`alphabetize.py` は SHA-256 で無変更を検証している）。

## バリデータ（scripts/validate5.mjs）が機械的に保証すること

1. **配点合計が16点**（3+2+2+4+5）。`pairs` は必ず `[[28,29],[30,31]]`。
2. `q27.choices` はちょうど4個。`answer` は 1〜4。
3. `q2831.choices` はちょうど**6個**（同じ語が2つ無いこと）。
   `blanks` は問28〜31 の4個。**`answer` の重複は本番同様に許容する**
   （「同じ選択肢を2回以上使ってもかまいません」）。
   `unused` は 6個から正解の集合を除いた**残りと完全一致**（個数は固定しない）。
4. **`heard` は講義スクリプトに文字どおり存在する**（言い換え元の実在を保証）。
5. **正解の語（choices[answer-1]）は講義スクリプトに出てこない**
   → 「聞こえた語をそのまま入れる」設計事故を検出する。第5問で最も重要な検査。
6. `collocationNote` が空でない。ワークシート本文に `(28)` 等の空所番号が実際に出現する。
7. `q32.matches` から導出した番号が `q32.answer` と一致。発言は各 8〜16語の**1文**。
8. `q33.answer` の選択肢が図表 `series` と矛盾しないこと（数値言及がある場合は数値を照合）。
9. **すべての keyPhrases が該当スクリプトに文字どおり存在する**（捏造解説の防止）。
10. `imagePrompt` は**英語のみ**（日本語が1文字でもあればエラー。GPT Image 2 は日本語で豆腐化する）。
    300字以上・`grayscale only` と `English only` を含む。
11. 語数：講義 265〜290語／問32 各8〜16語／問33 55〜80語。`wordCount` は実測と一致。
12. 15セット揃った時点で分布を集計（難易度・図表種類・話者性別・アクセント・問32答・問33答）。
