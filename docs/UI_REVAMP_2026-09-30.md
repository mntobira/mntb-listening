# UI 見直し（2026-09-30）

## ★決めたUIの決まり★（CLAUDE.md「UI principles」・src/styles/tokens.css の先頭にも記載）

1. **1画面でスクロールせずに完結させる。** 復習ノートも同じ。詳しい内容はタップで開く（アコーディオン・吹き出し）。スクロールが要るときは一覧の中だけ。
2. **同じ操作を2つ置かない**（例：解説の再生ボタンは上の1つだけ）。
3. **ホームの色の感じ・配置を変えない。** 他の画面をホームに合わせる。
4. 文字12px以上・タップ44px以上・コントラストAA。
5. 320×568／375×667／390×844／1280×800 で確認する。

## 課題の洗い出しと修正（2026-09-30 5回目・対戦中の画面）

対戦を実際に5〜6問ずつ進めて、問ごとに「選択肢が画面内に収まるか」を 320×568・375×667 で測った。

| 見つけた課題 | 直したこと |
|---|---|
| リスニング対戦で、場面説明の末尾に「Question: 〜」として設問と同じ英文が入り、太字の設問と2回出ていた | 重なっている部分だけ落とし、話者・場面の説明は残す |
| 長い場面説明（2〜3行）で選択肢が画面の下に押し出される | 低い画面では「場面 ▸ …」の1行にたたみ、タップで全文 |
| 「のこり3問」の帯が「3/5もん」の表示と重複して1行使う | 低い画面では見た目を消し、読み上げ用だけ残す |
| 相手の状態「第N問を考え中…」が 12px にしたことで2行に折り返す | 狭い画面は「第N問…」だけにし、折り返さない |
| 「LEAD」札 8px、対戦前の「BATTLE READY」説明 10px、結果の問番号 8px | 12px に |
| 「対戦をやめる」の上に余白（12px）があった | 低い画面ではなくした |
| リスニング解説の折りたたみ名が長く、320px で2行になる | 低い画面では「大問の流れ」「周辺知識」の短い名前にする |

結果：375×667 は英文の4択・絵の2×2とも1画面に収まる。

残り（次の作業）：320×568 で、図（地図など）＋英文の4択の問題と、長い設問の問題は、問題欄が少しスクロールする（最大 50px 程度）。この高さでは図・設問・4択・音源の帯を同時に入れきれないため、次は「図をタップで拡大・ふだんは小さく」または「選択肢を2列」にするかの判断が必要。
