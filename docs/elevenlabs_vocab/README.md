# 英単語帳の読み上げ音声を ElevenLabs で作る（全 5,713 語）

アプリの英単語帳・英単語4択の🔊は、いまは端末の読み上げ（機種によって声も発音もバラバラ）です。
ここにある原稿を ElevenLabs で読ませて送ってもらえれば、1語ずつに切ってアプリに入れます。
**録音がある語は録音、まだ無い語は今までどおり端末の読み上げ**になるので、一部だけ先に送ってもらっても大丈夫です。

## 1. 中身

| ファイル | 内容 |
|---|---|
| `ALL_PROMPTS.md` | **全119バッチの原稿（これを上から順に使う）**。見出しに保存するファイル名が書いてあります |
| `batches/*.txt` | 同じ原稿を1バッチ1ファイルにしたもの（1バッチ＝50語。最後のバッチだけ少ない） |
| `manifest.json` | バッチ → 語ID の対応（切り出しスクリプト用。触らない） |

| レベル | 語数 | バッチ数 |
|---|---:|---:|
| 単語 Lv1（共通テスト6割〜） | 1,185 | 24 |
| 単語 Lv2（共通テスト8割〜） | 962 | 20 |
| 単語 Lv3（2次試験レベル） | 653 | 14 |
| 単語 Lv4（2次試験の追加語彙） | 1,028 | 21 |
| 熟語 Lv1 | 1,524 | 31 |
| 熟語 Lv2 | 301 | 7 |
| 熟語 Lv3 | 60 | 2 |
| **合計** | **5,713** | **119** |

**よく使う Lv1 から順に**送ってもらえると、早く効果が出ます。

## 2. ElevenLabs の設定（全バッチで同じにする）

- 画面：**Text to Speech**
- モデル：**Eleven Multilingual v2**
  （`<break time="1.2s" />` の「間」が効くモデル。**Eleven v3 は break タグが効かない**ので使わない）
- 声：**アメリカ英語のはっきりした声を1つに決めて、最後まで変えない**
  （途中で声が変わると、単語ごとに声が違って聞こえる）
- Stability：**60〜70%**（高めにして、毎回同じ調子で読ませる）
- Similarity：75%　/ Style：**0%**　/ Speaker boost：オン
- Speed：**0.9**（単語帳なので、すこしゆっくり）
- 出力：**MP3 44.1kHz 128kbps**（それ以上でも可）

## 3. やること（1バッチごと）

1. `ALL_PROMPTS.md` の次の見出し（例：`lv1_0001-0050`）の枠の中を**全部**コピー
2. ElevenLabs に貼って生成
3. 聞いて、**途中で読み飛ばし・言い直しがないか**だけ確かめる（気になる語があれば、そのバッチだけ作り直し）
4. 見出しのファイル名で保存（例：`lv1_0001-0050.mp3`）
5. 何バッチかたまったら、まとめて送る（zip でも、フォルダごとでも）

※ 原稿の `…` は「ここに語句が入る」場所です（例：`so … that`）。少し間を空けて読まれます。
※ `A` `B` は「A を B に」の A・B です（例：`prefer A to B`）。そのまま「エー」「ビー」で読まれます。

## 4. 文字数（クレジット）の目安

- 読む英語そのものは約 **5.6 万文字**
- 間を作るタグ（`<break time="1.2s" />`）も文字数に数えられる場合があり、その場合は全部で最大 **約 18.5 万文字**
- 足りなければ、レベルごと（Lv1 だけ、など）に分けて進めてください

## 5. 受け取ったあと（こちらでやること）

```bash
# 送ってもらった mp3 を1つのフォルダに入れて
python3 scripts/vocab-audio/cut.py <そのフォルダ>
```

- 1.2 秒の間を目印に1語ずつに切り、音量をそろえて `public/audio/vocab/<レベル>/<番号>.mp3` に置きます
- **語の数と間の数が合わないバッチは切りません**（ずれた音声を入れない）。`cut_report.md` に「×」で出るので、そのバッチだけ作り直しをお願いします
- アプリは `public/audio/vocab/index.json` に載っている語だけ録音を使い、ほかは端末の読み上げのままです

## 6. 原稿を作り直すとき

単語データ（`public/data/listeningVocabulary.json`）が変わったら：

```bash
python3 scripts/vocab-audio/make_prompts.py
```

読み方の直し（`～` `人` `A/B` などの扱い）は `scripts/vocab-audio/spoken.py` にあります。
