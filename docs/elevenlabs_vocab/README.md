# 英単語帳の読み上げ音声を ElevenLabs で作る（全 5,713 語）

アプリの英単語帳・英単語4択の🔊は、いまは端末の読み上げ（機種によって声も発音もバラバラ）です。
ここにある原稿を ElevenLabs で読ませて送ってもらえれば、1語ずつに切ってアプリに入れます。
**録音がある語は録音、まだ無い語は今までどおり端末の読み上げ**になるので、一部だけ先に送ってもらっても大丈夫です。

## 1. 中身

| ファイル | 内容 |

| `ALL_PROMPTS.md` | 同じ原稿をテキストでまとめたもの |

**よく使う Lv1 から順に**送ってもらえると、早く効果が出ます。

## 2. ElevenLabs の設定（全バッチで同じにする）

- 画面：**Text to Speech**
- モデル：**Eleven Multilingual v2**
  （`<break time="1.2s" />` の「間」が効くモデル。**Eleven v3 / v4 は break タグが使えない**ので使わない：ElevenLabs 公式ドキュメント）
- 声：**アメリカ英語のはっきりした声を1つに決めて、最後まで変えない**
  （途中で声が変わると、単語ごとに声が違って聞こえる）
- Stability：**60〜70%**（高めにして、毎回同じ調子で読ませる）
- Similarity：75%　/ Style：**0%**　/ Speaker boost：オン
- Speed：**0.9**（単語帳なので、すこしゆっくり）
- 出力：**MP3 44.1kHz 128kbps**（それ以上でも可）

## 3. やること（1バッチごと）

1. PDF の次のページ（例：`lv1_0001-0030.mp3`）の**点線の枠の中を全部**コピー（見出しは入れない）
2. ElevenLabs の入力欄を**空にしてから**貼って生成
3. 聞いて、**途中で読み飛ばし・言い直しがないか**だけ確かめる（気になる語があれば、そのバッチだけ作り直し）
4. 見出しのファイル名で保存（例：`lv1_0001-0030.mp3`）。付け忘れても、語の長さの並びでたいてい見分けられます
5. 何バッチかたまったら、まとめて送る（zip でも、フォルダごとでも）

※ 原稿の `—` は「ここに語句が入る」場所です（例：`so — that`）。少し間を空けて読まれます。
  （`…` はためらうような読み方になるので使っていません：ElevenLabs 公式ドキュメント）
※ 1回を30語にしているのは、間の指定が多すぎると「読む速さが上がる・雑音が入る」ことがあるためです（同上）。
※ `A` `B` は「A を B に」の A・B です（例：`prefer A to B`）。そのまま「エー」「ビー」で読まれます。

## 4. 文字数（クレジット）の目安

- 読む英語そのものは約 **5.6 万文字**
- 間を作るタグ（`<break time="1.2s" />`）も文字数に数えられる場合があり、その場合は全部で最大 **約 18 万文字**
- 足りなければ、レベルごと（Lv1 だけ、など）に分けて進めてください

## 5. 受け取ったあと（こちらでやること）

```bash
# 送ってもらった mp3 を1つのフォルダに入れて
python3 scripts/vocab-audio/cut.py <そのフォルダ>
```

- 1.2 秒の間を目印に1語ずつに切り、音量をそろえて `public/audio/vocab/<レベル>/<番号>.mp3` に置きます（1語 約5KB、全部で 約30MB）
- zip のまま・サブフォルダに入ったまま・名前に余計な文字が付いたままでも読めます
- **ずれた音声は入れません。** 次のどれかに当たる回は切らずに `cut_report.md` に「×」で出します（その回だけ作り直し）
  - 間の数が足りない（読み飛ばし）／切れ目が1つに決まらない（語が多い・言い直し）
  - 極端に短い・長い語がある（2語がつながった）／語の長さの並びが原稿と合わない
  - 無音・壊れたファイル
- アプリは `public/audio/vocab/index.json` に載っている語だけ録音を使い、ほかは端末の読み上げのままです
- 録り直したときは版（`rev`）が変わるので、古い音がキャッシュに残りません

## 6. 原稿を作り直すとき

単語データ（`public/data/listeningVocabulary.json`）が変わったら：

```bash
python3 scripts/vocab-audio/make_prompts.py   # 原稿・manifest
python3 scripts/vocab-audio/make_pdf.py       # PDF（PDF から取り出した文字が原稿と1文字ずつ同じか確かめて止まる）
```

読み方の直し（`～` `人` `A/B` などの扱い）は `scripts/vocab-audio/spoken.py` にあります。
