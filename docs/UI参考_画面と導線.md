## 3. 新しい科目選択画面のデザイン（ListeningSubjectSelection）

- **見出し**「聞く力と、その土台。」— リスニングを軸に英文法・英単語を固める、という位置づけを一言で。
- **メイン**：英語リスニングを緑の大きいカード（ホームの「リスニングを始める」と同じ色・影）。
- **「英文法・英単語を固める」ブロック**：3つのカードを1つの枠にまとめた（スマホ＝縦1列、PC＝横3列）。
  - 英文法の演習（全20単元・4択100問）／英単語・英熟語（5,713語）／聞き取りの文法（8ポイント）
  - 下に「対戦で固める」（英文法・英単語もAI・友だち・全国対戦で選べる）
- 選択中の科目は金色の枠（`aria-current`）。
- タップ領域はすべて 44px 以上。320px 幅でも横はみ出しなし（確認済み）。
- 色：緑 `#216957`・背景 `#f5f5ef`・枠 `#dde3d4`・対戦の青 `#e8eef2`（ホームと共通）。
